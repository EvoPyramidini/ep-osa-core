# retrieval

Integration contracts for retrieval flows consumed by orchestration.

## Note
Retrieval infrastructure is external to EP-OSA-Core. This directory defines how retrieval outputs are consumed, not how memory backends are implemented.
This directory is reserved for the topology-first EP-OSA architecture.

## Purpose
- Keep runtime lightweight and orchestration-centric.
- Isolate concerns from memory and capability ecosystems.

## Status
- Scaffold only; implementation to be introduced incrementally.
