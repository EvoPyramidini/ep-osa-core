# Руководство по совместной работе с ИИ

Эта инструкция поможет вам эффективно использовать ИИ для создания вашей системы.

### Как работать с чат-ИИ
1. Формулируйте вопросы ясно.
2. Просите объяснить сложные концепты.
3. Сохраняйте все диалоги для анализа.

### Структура и файлы
Всё разбито на следующие категории:
- **sessions/** - Здесь диалоги и сессии.
- **code_drafts/** - Черновики кода.
- **approved_patterns/** - Подтверждённые паттерны.

Начните с сохранения первой сессии!
