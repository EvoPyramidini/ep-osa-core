# EP-OSA Terminology

- **intent**: normalized representation of a requested outcome.
- **policy**: governance rule defining what is allowed/forbidden.
- **contract**: interface agreement between layers/modules.
- **route**: topology path from validated intent to execution capability.
- **decision**: traceable runtime selection made by orchestration.
- **execution envelope**: constrained environment where actions run.
- **scope-partitioned memory**: memory segmented by context and authority.
