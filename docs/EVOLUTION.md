# Evolution Roadmap

## Current phase
Stabilize architecture topology before large-scale feature expansion.

## Near-term priorities
1. Harden directory topology and ownership boundaries.
2. Preserve isolation between core, memory, and capability layers.
3. Add contracts before implementation-heavy modules.
4. Scale by composition, not by centralization.

## Success criteria
- Architecture can evolve without runtime bloat.
- New modules can be added with explicit scope and interfaces.
- Context systems remain externally composable.
