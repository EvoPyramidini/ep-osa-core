# Field Orchestration and Layered Routing

## Intent
EP-OSA behavior is modeled through orchestrated fields and layered topology traversal, not centralized autonomy.

## Dual-layer Pyramid model
### A) Memory layers (colored)
Contain cognition artifacts:
- operational experience;
- semantic memory;
- execution history;
- contextual traces;
- instructions;
- outcomes;
- agent interactions;
- successful patterns.

### B) Capability/backend layers (gray)
Contain execution artifacts:
- tools;
- scripts;
- services;
- automation chains;
- providers;
- execution environments;
- integrations;
- infrastructure routes.

## Z-layer routing example
- **Z17**: receives user/system intent.
- **Z16**: reconstructs context and retrieves relevant memory/experience.
- **Gray connector layer**: maps required capabilities and execution routes.
- **Z15**: resolves tools/scripts/environments and activates chains.

Deeper layers correspond to increasingly specialized infrastructure.

## Constraint
The Pyramid remains an orchestration and cognitive-topology surface; heavy execution remains external.
