# Field Orchestration and Guided Infrastructure Model

## Intent
EP-OSA behavior is modeled as constrained operational cognition inside a guided infrastructure field, not centralized autonomy.

## Operational metaphor (normative)
The model can be communicated with a puck/board/magnet analogy:
- **Puck** -> Agent (bounded executor).
- **Board** -> Topology and routing environment.
- **Drawn routes/zones** -> Infrastructure affordances and activation points.
- **Magnet under board** -> Hidden orchestration backend and routing force.

This is not decorative language; it is a design contract that clarifies what agents can and cannot do.

## Architecture mapping
### Agent (puck)
- cannot know the full system state;
- cannot bypass orchestration contracts;
- adapts behavior from observable field effects.

### Topology surface (board)
- defines semantic and operational geography;
- constrains legal transitions;
- provides deterministic routing hints when available.

### Affordances (routes/zones)
- expose available execution paths;
- mark entry points into capability chains;
- provide operational context for selection and sequencing.

### Orchestration force (magnet)
- coordinates hidden backend decisions;
- applies policy/scheduling constraints;
- steers execution through approved pathways.

## Dual-layer Pyramid model
### A) Memory layers (colored)
Contain cognition artifacts:
- operational experience;
- semantic memory;
- execution history;
- contextual traces;
- instructions;
- outcomes;
- agent interactions;
- successful patterns.

### B) Capability/backend layers (gray)
Contain execution artifacts:
- tools;
- scripts;
- services;
- automation chains;
- providers;
- execution environments;
- integrations;
- infrastructure routes.

## Z-layer routing example
- **Z17**: receives user/system intent.
- **Z16**: reconstructs context and retrieves relevant memory/experience.
- **Gray connector layer**: maps required capabilities and execution routes.
- **Z15**: resolves tools/scripts/environments and activates chains.

Deeper layers correspond to increasingly specialized infrastructure.

## Predictive operational cognition
Agents should not act as free-will controllers. They should:
- infer likely orchestration trajectories from field signals;
- predict viable execution paths;
- select actions that preserve topology constraints.

## Constraint
The Pyramid remains an orchestration and cognitive-topology surface; heavy execution remains external.
