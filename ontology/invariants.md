# EP-OSA Invariants

1. Governance precedes execution.
2. Execution requires validated intent.
3. Agents operate under contracts, never raw free-form control.
4. Memory and capability layers are externalized from core orchestration runtime.
5. All runtime decisions are auditable and replayable.
6. No environment-specific chat/session state is treated as canonical project memory.
7. Runtime continuity must be reconstructable from repository artifacts.
