# memory-bridges

Contracted integration surfaces between EP-OSA-Core orchestration and external memory ecosystems.

## Purpose
- reconstruct context from external memory layers;
- expose memory-derived signals to routing/topology decisions;
- keep memory systems decoupled from core runtime internals.
This directory is reserved for the topology-first EP-OSA architecture.
