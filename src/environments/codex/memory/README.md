# Codex Memory

This directory stores durable Codex-specific memory for EP-OSA sessions.

Use it for:

- stable implementation preferences;
- known repository conventions;
- recurring user instructions;
- environment-specific constraints;
- handoff anchors that should survive chat loss.

Do not use it for:

- secrets;
- transient guesses;
- unverified claims;
- application business data that belongs elsewhere.

Memory entries should be explicit, dated when useful, and tied to source files when possible.
